# Brand attributes

- `web_eligible` — the brand may be sold on the website. Set by merchandising.
- `is_searchable` — the brand appears in site-search suggestions. Can be true for
  store-only brands (customers search for them to find a store).
- `fulfillment_type` — how orders ship: `ship`, `store_only` or `dropship`.
- `status` — `active`, `paused` (temporarily off everywhere) or `retired`.
